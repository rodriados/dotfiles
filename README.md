# dotfiles
![license MIT](https://img.shields.io/badge/license-MIT-lightgrey.svg)

This repository contains [**@rodriados**](https://github.com/rodriados)'s personal
dotfiles and scripts.

## Motivation
Whenever I have to start using or working with a new machine, it is always tiresome
and time demanding to configure the system to be of my personal liking. Sometimes,
for instance, some specific settings, that might have taken me a long time to configure,
is lost and I must figure everything out once again.

For that reason, it is typical for developers to save their so-called dotfiles in
a repository to quickly recreate their working environment.

Here are mine! Feel free to copy them if you find them useful.
